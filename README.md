# realTasia API archive

This repository preserves the historical API service behind realTasia, a social-property platform built and operated in Singapore between 2012 and 2014. It contains the OAuth boundary, resource and permission model, social interactions, people, companies, properties, conversations, media and the rules connecting them.

This public repository preserves the historical commit sequence with identifying data redacted, followed by a modern archival snapshot. The untouched original remains in the private archival master. Modern documents identify themselves as editorial additions.
